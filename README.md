# BoboCloset 🧺 Quokka & Bobo 簡約奶油風穿搭資料庫平台

以 **Quokka & Bobo 韓系簡約奶油風格** 打造的個人智慧衣櫥與情境穿搭顧問 Web App（支援 iPhone「加入主畫面」Standalone PWA、Safari 與電腦跨瀏覽器永久雲端同步）。

## ✨ 核心特色

1. **雙模式衣服入庫（AI 對話建檔 × 手機隨拍即存）**
   - **傳照片給 AI**：直接拍衣服照片或描述單品傳給 AI，即可入庫至 `public/wardrobe/` 與 `src/data/defaultWardrobe.ts` 並自動部署至 GitHub Pages。
   - **手機隨拍新增**：內建相機／相簿照片自動智慧壓縮與**主色系自動辨識**，尚未拍照時亦會套用同色系奶油手繪服飾插畫。
2. **時間 × 地點 × 天氣溫度 × 場合 智慧穿搭顧問**
   - 依出門時段、氣溫、晴雨／冷氣房、場合性質、指定必穿單品與同行友人（防重複撞衫提醒），自動排除待洗單品並推薦 Top 3 套完整奶油配色穿搭。
3. **穿搭靈感簿 ＆ OOTD 對鏡自拍日記**
   - 收藏穿搭提案、記錄實穿日期與見面對象、上傳每日 OOTD 對鏡自拍照並自動統計單品實穿次數。
4. **跨瀏覽器永久雲端同步與本機防清除保護**
   - 內建 `SHA-256` 通行碼衍生雲端保險箱（含單品照片分片永久同步）、防空白覆蓋合併與墓碑紀錄、`IndexedDB` 雙重鏡像備份與 `.json` 匯出匯入。
